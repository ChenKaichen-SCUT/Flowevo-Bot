# 失败审计与分类

历史MATH基于已关闭gold反馈的Flowevo-Bot500首轮，保留原始464/500。9个明确假阴性复核后可探索性记为473/500，但原464个正确项没有全量重新逐题复审，不能覆盖原发布记录。失败案例逐题包含题面、完整输出、答案、证据、位置和未知点。

历史代码必须从首轮重新计算：434/500首轮正确、66首轮失败；原报告472/500最终正确、28最终失败经过最多5次调用。L2两次温度.5、L3温度.7、L4温度.2，与本轮最多一次额外调用不等价。三条官方测试在当时全部公开；验证与早期经验可能使用同一公开测试集，因此不是隐藏测试准确率，也不作为新Memory来源。快照保留了500个首轮原始请求响应、收据和题目。

历史数学主标签：27 Truncation Failure、9 Evaluator/Environment Issue。历史代码：27 Truncation Failure、26 Answer/Format Failure、13 Verification Failure（根因未确定）。66个代码旧失败的当前提取与原candidate全部相同；其中26个换成公开函数定义块后在原三条公开测试上通过，无新API调用。

九类体系：

| 类别 | 本轮证据/边界 |
| --- | --- |
| Answer/Format Failure | 首个代码块是示例/测试，完整函数位于后面；免费提取即可通过 |
| Truncation Failure | provider finish_reason=length；不能据此断言解题能力不足 |
| Local Calculation Failure | 当前有界整数检查未定位到可确认的本地算错；计数为0，不强造案例 |
| Constraint Failure | 训练prealgebra76自行要求精确付款，忽略可找零解释；相对数据参考属于约束假设问题 |
| Strategy Failure | 代码968选择min解释不能通过隐藏题，但题面缺公式；仅列候选次标签 |
| Verification Failure | 执行失败已知、算法还是局部实现根因不明 |
| Insufficient Reasoning | 不能从截断或单次失败直接推断，本轮无可独立确认主标签 |
| Evaluator/Environment Issue | 单位/度数/货币/百分号/逗号及多正确答案；还有题面不足和提取器因素 |
| Unknown | 证据不足即保留未知，不利用gold把猜测写成在线诊断 |

确认样本有35个首轮正确控制、13个首轮失败：数学19正确/5截断，代码16正确/7提取问题/1未知语义失败。未达到预期8–12个数学自然失败；不为了凑数继续消耗调用。训练新增32代码首轮的11个失败包括8格式、2验证、1截断；其中只选8题尝试反事实，4题完整。全部133个失败/评分异常案例按stage隔离，不能混成一个准确率分母。

数学截断训练6题、确认5题的可见正文为空；新调用原始响应保留provider reasoning token计数。这不是有可复用可见推理前缀的“继续解题”实验。

9个旧数学评分异常的完整证明在 failure_cases.jsonl。确认后的3个自动unknown单独显式复核，没有改变在线选择，也没有改动冻结评分器。
