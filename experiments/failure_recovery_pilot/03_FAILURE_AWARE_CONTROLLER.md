# A：公开失败信号控制器

输入是严格的Task/State结构：题面、公开测试、已有输出、截断标记、实际token。禁止gold_answer/correct/hidden_tests等额外字段。在线特征只来自输出结束原因、最终答案标记、编译、第一条公开测试和有界整数等式校验。后者保留反例位置但不推断整题一定错误。

| 方法 | 预定动作 |
| --- | --- |
| 单次 | 全部停止 |
| 固定重试 | 全部独立重新生成一次 |
| 确定性重试 | 截断、编译或公开测试失败时Retry |
| A | 环境限制先停止；截断→Continue；公开编译/测试失败或局部整数矛盾→Repair；缺最终答案→Continue；其余停止 |
| C | A同样的触发边界，根据冻结训练经验改变动作，证据不足回退A |
| 打乱经验 | 相同检索规则，但训练记录的动作标签按固定种子打乱 |

所有方法选择恢复后直接提交该分支，不根据隐藏评分回退旧答案，不选择“答对的最好分支”。正确控制自然进入确认，固定重试误触发35次、损害2题；A/确定性/C均触发12次、原提取协议下0正确题误触发。这个零误触发受7个代码接口错误影响：免费提取修正后这7次不再是语义恢复需要。

公开信号表见 evidence/diagnostic_signals.csv：数学截断检出5/5，代码公开测试检出7/8，局部矛盾0触发。数学统计只有5个失败，不能声称泛化100%召回；代码漏掉的968正是公开测试通过、隐藏测试不通过的规格歧义。

API真实峰值8，本地进程12；执行沙箱在子进程预载标准库后禁止文件打开、网络连接和派生进程，并限制内存、CPU和墙钟。仅用于标准数据集，环境问题显式记录。参考程序在调用前预检；1个不兼容import题替换，2个跨划分近重复题替换。没有使用确认输出来换题。
